# Vehicle assets

Original, unmodified GLB models and palette texture from [Kenney Car Kit 3.1](https://kenney.nl/assets/car-kit), licensed CC0. See LICENSE.txt. Downloaded 2026-09-10 from the download linked on the official asset page. No branded vehicle names are used in the app.

- sedan.glb — Everyday sedan
- hatchback-sports.glb — Sport hatchback
- suv.glb — Trail SUV
- Textures/colormap.png — shared external palette required by all three GLBs

Source archive SHA-256: `fac7dacac5c7874348cf19729af3ef205f3d366493edaf0a827d93f4fdf3d0c4`.

Runtime normalization, body-only paint, wheel pivots and lighting are in `vehicleModels.ts`. Original files are retained for reproducibility. No runtime third-party downloads or accounts are required.
